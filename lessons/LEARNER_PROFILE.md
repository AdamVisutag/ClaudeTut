**Date:** May 2026
**File:** `lesson-01-git-and-github.pdf`

**What was covered:**
- Git vs GitHub — the core distinction and mental model
- Version control — commits as snapshots, the 3-step workflow

- Cloning vs forking — getting any repo running locally
