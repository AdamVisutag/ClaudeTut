# Adam's Dev Learning Journey

This repository is a personal record of my path from non-technical founder to hands-on developer.

I'm an entrepreneur who has led software products and development teams for years — and now I'm learning to build the backend and frontend myself. This repo is where I experiment, practice, and document everything I pick up along the way.

## What's in here

### `/lessons`
Structured lesson documents (PDF + HTML source) covering the concepts and tools I'm learning, generated during live sessions. Each lesson reflects what was actually built and practiced — not generic tutorials.

| Lesson | Topic |

### Projects & experiments
As I learn, I'll build real things here — small apps, prototypes, and experiments. Everything committed to this repo is something I built or learned hands-on.

## Where I'm starting from

- Strong product instincts and UX thinking from years of building companies
- Experience directing engineering teams and shipping products
- Now learning: HTML, CSS, JavaScript, backend development, databases, APIs

## Goal

To go from directing developers to being able to build and ship full-stack products myself.
